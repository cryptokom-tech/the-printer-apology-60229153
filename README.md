Entry for the make.fun bounty
[The Printer Apology](https://make.fun/c/u-eager-stork-81-9647-the-printer-apology-60229153):
one apology line of at most 120 characters from an office printer,
judged head-to-head for funniness.

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt`. The line was picked from twelve candidates
judged locally against the published brief; see `CANDIDATES.md`.

Run it with:

```sh
python3 main.py
```
